# 🍽️ TasteAR – Restaurant Augmented Reality Menu

TasteAR is a browser-based WebAR application that allows restaurant customers to preview food items in Augmented Reality before ordering.

Built using **MindAR**, **A-Frame**, and **HTML/CSS/JavaScript**, the project works directly in a mobile browser without requiring any application installation.

## ✨ Features

- 🍔 Interactive restaurant menu
- 📱 Browser-based Augmented Reality
- 🎯 Image Target Tracking using MindAR
- 📷 Camera-based AR experience
- ⚡ No mobile app required
- 🎨 Modern restaurant UI

## 🚀 How It Works

1. Open the menu page.
2. Select a food item.
3. Allow camera permission.
4. Point the camera at the restaurant's target image.
5. View the selected food item in Augmented Reality.
